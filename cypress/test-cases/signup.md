# Casos de Teste - Signup

## CT-SIGNUP-001 - Cadastro de novo usuário

**Passos:**
1. Acessar a tela de cadastro.
2. Preencher os campos obrigatórios com dados válidos.
3. Confirmar o cadastro.

**Resultado esperado:**
O usuário deve ser cadastrado com sucesso.

**Status:** ✅ Automatizado com Cypress

## CT-SIGNUP-002 - Validação de campos obrigatórios

**Passos:**
1. Acessar a tela de cadastro.
2. Deixar os campos obrigatórios vazios.
3. Tentar realizar o cadastro.

**Resultado esperado:**
O sistema deve apresentar as validações dos campos obrigatórios.

**Status:** ✅ Automatizado com Cypress
